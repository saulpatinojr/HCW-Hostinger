# ADR-0003: Runner deployed as a Docker container, not a systemd service

## Status

Accepted — 2026-06-26

## Context

GitHub's official runner ships as a tarball with a `config.sh` script. The standard deployment is to install it as a systemd service: extract, run `config.sh` to register, install via `svc.sh install`.

The alternative is to wrap the runner in a Docker container. `myoung34/github-runner` is the most-used community image and bakes in the GitHub App registration flow.

## Decision

Deploy the runner as a Docker container managed by Docker Compose, using the `myoung34/github-runner:latest` image.

Mount the host's `/var/run/docker.sock` into the container so the runner can spawn its own containers for build steps. Run `privileged: true` so we can spin up `kind` clusters for k8s integration tests.

## Consequences

**Positive**
- Container restart re-runs the full registration handshake, automatically replacing any stale "Offline" runner entries in the GitHub UI
- Upgrades are `docker compose pull && docker compose up -d` — no SSH-in, stop service, replace binary
- Persistent state stored in a named volume (`runner_work`), trivially backed up
- Auth via env vars instead of a config file makes secret rotation atomic
- The same compose file works for adding a second runner on the same host (just change the container name)

**Negative**
- `privileged: true` is a significant trust grant. Acceptable here because we only build our own code. NOT acceptable for runners that accept untrusted PR contributions.
- Mounting the Docker socket effectively grants root on the host. Same trust caveat.
- Image updates are pinned to `:latest`. A surprise breaking change in the upstream image can break us. Mitigated by `restart: unless-stopped` not retrying forever on bootloop, but worth pinning to a specific tag once we hit a stable known-good version.

## Code

The compose file generated by Ansible:

```yaml
services:
  runner:
    image: myoung34/github-runner:latest
    restart: unless-stopped
    environment:
      RUNNER_SCOPE: repo
      REPO_URL: "https://github.com/{{ github_repo }}"
      APP_ID: "{{ github_app_id }}"
      APP_LOGIN: "{{ github_repo.split('/')[0] }}"
      APP_PRIVATE_KEY: |
{{ github_app_private_key | b64decode | indent(8, first=True) }}
      RUNNER_NAME: "{{ ansible_facts['hostname'] }}"
      LABELS: "{{ github_runner_labels }}"
      RUNNER_WORKDIR: /tmp/runner/work
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - runner_work:/tmp/runner
    privileged: true

volumes:
  runner_work:
```
